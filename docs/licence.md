# Licence and citation

## What you may do

Free to use for:

- research, including research inside a company
- teaching and education
- personal, hobby and evaluation use
- including in open-source software that is given away at no charge, under a
  licence permitting these same uses

## What needs permission

Selling this software, or building it into a product or service that is sold or
run for commercial advantage, requires written permission from the copyright
holder. That applies whether or not the software itself reaches the end user.

The full text is in [LICENSE](https://github.com/iamkucuk/eulerian-video-magnification-cuda/blob/main/LICENSE).

## Why it is not a standard open-source licence

The method comes from work published by MIT, whose own reference code is
released for research use only. This project keeps that restriction rather than
appearing to grant rights it cannot grant. One consequence worth stating: the
licence is not approved by the Open Source Initiative, so this project cannot be
submitted to journals that require such a licence, and some organisations'
policies will exclude it.

## Citing it

Any publication using this software must cite it. The licence contains the
required form:

> Kucuk, Furkan. "Eulerian Video Magnification on CUDA."
> https://github.com/iamkucuk/eulerian-video-magnification-cuda, 2026.

Please also cite the original method:

> Wu, H., Rubinstein, M., Shih, E., Guttag, J., Durand, F., and Freeman, W.
> "Eulerian Video Magnification for Revealing Subtle Changes in the World."
> ACM Transactions on Graphics (SIGGRAPH), 2012.
